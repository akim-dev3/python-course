Суть

Три фундаментальных инструмента: оценка эффективности (Big O), рекурсия и бинарный поиск. Это база перед паттернами two pointers и sliding window (Модуль 5).

Big O — сложность алгоритмов

Таблица

Сложность Имя Пример На 1 000 000 элементов
O(1) Константа dict["key"], lst[0] 1 операция
O(log n) Логарифм Бинарный поиск ~20 операций
O(n) Линейная Один цикл, фильтр 1 000 000 операций
O(n log n) Линейно-лог sorted() ~20 000 000 операций
O(n²) Квадратичная Цикл внутри цикла 10¹² операций

Правила чтения кода

  • Один цикл по n → O(n)
  • Два последовательных цикла по n → O(n + n) = O(n) (константы отбрасываем)
  • Два вложенных цикла по тем же данным → O(n²)
  • Цикл по n × цикл по m → O(n·m)
  • Делим диапазон пополам → O(log n)
  • dict["key"], lst[i] → O(1)
  • "x" in list → O(n), "x" in set → O(1)
  • sorted(lst) → O(n log n)
  • lst.append() → O(1), lst.insert(0, x) → O(n) (сдвиг всех)

Пространственная сложность

Отдельно от временной. Сколько памяти алгоритм использует сверх входа.

# O(1) памяти — переменные не растут с n
def sum_list(lst):
    total = 0
    for x in lst:
        total += x
    return total

# O(n) памяти — новая структура размера n
def doubled(lst):
    return [x * 2 for x in lst]

# O(n) памяти — рекурсия копит стек вызовов
def factorial_rec(n):
    if n <= 1:
        return 1
    return n * factorial_rec(n - 1)

Когда выбираешь между set и сортировкой — учитывай оба измерения. set даёт O(1) lookup, но O(n) памяти.

Ключевая оптимизация: list → set

# МЕДЛЕННО O(n²): вложенный цикл
for i in range(len(lst)):
    for j in range(i + 1, len(lst)):
        if lst[i] == lst[j]:
            return True

# БЫСТРО O(n): set — O(1) lookup
seen = set()
for x in lst:
    if x in seen:
        return True
    seen.add(x)
# Или одной строкой:
return len(lst) != len(set(lst))

find_pair_sum — O(n) через set

def find_pair_sum(lst, target):
    seen = set()
    for x in lst:
        if (target - x) in seen:   # O(1)
            return (target - x, x)
        seen.add(x)
    return None

Рекурсия

Шаблон

def func(n):
    if <базовый случай>:        # СТОП
        return <значение>
    return func(<меньший n>)    # шаг ближе к базе

Базовые случаи по типу задачи

Тип Базовый случай
Числа (факториал, степень) if n <= 0: return 1
Списки if not lst: return []
Строки if not s: return ""
Вложенные структуры if not children: return 0

Примеры

def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

def sum_digits(n):              # sum_digits(123) = 6
    if n == 0:
        return 0
    return (n % 10) + sum_digits(n // 10)

def reverse_string(s):
    if len(s) <= 1:
        return s
    return reverse_string(s[1:]) + s[0]

def flatten(nested):            # любая глубина
    result = []
    for item in nested:
        if isinstance(item, list):
            result.extend(flatten(item))
        else:
            result.append(item)
    return result

def count_nested(data, key, value):   # поиск в дереве
    count = 0
    for item in data:
        if item.get(key) == value:
            count += 1
        count += count_nested(item.get("children", []), key, value)
    return count

Когда использовать рекурсию

  • Вложенные структуры неизвестной глубины (JSON, org chart)
  • Математические последовательности (факториал, Фибоначчи)
  • Простой проход по списку → цикл проще

Рекурсия vs итерация

# Рекурсивно — короче, но O(n) памяти на стек вызовов
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

# Итеративно — O(1) памяти, без риска RecursionError
def factorial(n):
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

Python имеет лимит глубины рекурсии (~1000). Для больших n или глубоких структур — итеративный вариант предпочтительнее.

Мемоизация — спасение от экспоненциальной сложности

# Наивная Фибоначчи — O(2ⁿ), считает одно и то же много раз
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

# fib(35) — несколько секунд

# Ручная мемоизация через dict — O(n)
cache = {}
def fib(n):
    if n in cache:
        return cache[n]
    if n < 2:
        return n
    cache[n] = fib(n - 1) + fib(n - 2)
    return cache[n]

# Автоматическая через functools — O(n), одна строка
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

# fib(100) — мгновенно

@lru_cache запоминает результат для каждого набора аргументов. Применимо к чистым функциям (без побочных эффектов).

Бинарный поиск

Алгоритм (выучить)

def binary_search(lst, target):
    left, right = 0, len(lst) - 1
    while left <= right:
        mid = (left + right) // 2
        if lst[mid] == target:
            return mid
        elif lst[mid] < target:
            left = mid + 1      # target правее
        else:
            right = mid - 1     # target левее
    return -1

Условие: работает ТОЛЬКО на отсортированном списке.

Вариации

# Поиск в списке словарей
def binary_search_by_field(data, sort_field, target):
    left, right = 0, len(data) - 1
    while left <= right:
        mid = (left + right) // 2
        mid_val = data[mid].get(sort_field)
        if mid_val == target:   return data[mid]
        elif mid_val < target:  left = mid + 1
        else:                   right = mid - 1
    return None

# Позиция вставки
def find_insert_position(lst, value):
    left, right = 0, len(lst)
    while left < right:
        mid = (left + right) // 2
        if lst[mid] < value:  left = mid + 1
        else:                 right = mid
    return left

Ошибка Правило
Забыть базовый случай RecursionError — всегда нужна точка остановки
